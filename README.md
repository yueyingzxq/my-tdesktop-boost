## 📥 新手从零上手指南（2分钟搞定）

无论您是第一次使用 Telegram，还是从原版转过来的老玩家，跟着以下步骤即可轻松配置：

### 第一步：下载软件
前往 [**Releases 页面**](https://github.com/yueyingzxq/my-tdesktop-boost/releases/tag/latest-boost) 下载最新版本的 `Telegram_x64_qt6.zip`。

> 💡 **放置建议**：
> 将压缩包解压到一个独立的日常文件夹（推荐如 `D:\Software\Telegram\` 或 `E:\Telegram_Boost\`）。
> **请勿解压在 C 盘 Program Files 或桌面临时文件夹**，防止 Windows 读写权限限制导致自动更新失败。

### 第二步：网络代理配置（国内必配）
Telegram 在国内需要配合代理软件（v2rayN、Clash 等）使用：

1. **软件内手动配置（最通用）**：
   - 打开您的代理软件，确保正常开启。
   - 打开 `Telegram.exe`，在登录界面点击左下角或右上角的【小盾牌/连接设置】（或者进入 **设置 -> 高级 -> 连接类型 -> 使用自定义代理**）。
   - 点击 **【添加代理】**：
     - **代理类型**：选择 `SOCKS5` 或 `HTTP`
     - **服务器**：填 `127.0.0.1`
     - **端口**：填您的代理本地端口（v2rayN 一般为 `10808` 或 `10809`；Clash 一般为 `7890`）
   - 保存后界面显示【已连接】，即可畅通无阻！
2. **快速跳转链接**：
   在代理工具开启状态下，浏览器打开即可自动配置：
   - v2rayN：`tg://socks?server=127.0.0.1&port=10808`
   - Clash：`tg://socks?server=127.0.0.1&port=7890`

### 第三步：老用户数据无缝迁移（免重新登录）
如果您以前用过官方 Telegram 或其他 Telegram 客户端：
1. 退出之前的 Telegram。
2. 打开旧版所在的文件夹，找到名为 **`tdata`** 的文件夹。
3. 把整个 `tdata` 文件夹**复制**到本增强版的文件夹中。
4. 双击打开 `Telegram.exe` —— **瞬间免密免验证码登录，所有联系人、聊天记录、置顶完全一致！**

### 第四步：界面汉化（可选）
官方默认无简体中文，可以在任意聊天框点击或在浏览器打开下方官方汉化包链接：
👉 [点击一键安装简体中文语言包](https://t.me/setlanguage/zhcncc)

## 🔄 软件更新说明

本版本直接接入了 GitHub Releases 官方原生更新流：
1. **软件内一键无缝更新（首选）**：
   当仓库有新构建发布后，Telegram 左侧聊天列表最下方会自动亮起蓝色的 **【更新 Telegram】** 按钮（或在“设置 -> 高级 -> 检查更新”）。
   直接点击该按钮，软件自动在后台下载并毫秒级重启完成更新，**个人数据与登录状态 100% 完整保留**。
2. **备用一键更新脚本**：
   目录下附带 `一键更新.bat`，如遇特殊网络状况也可双击执行强力更新。

## 🛠️ 项目构建说明（开发者）

本仓库由 GitHub Actions (`.github/workflows/win.yml`) 自动化流水线编译打包。

- **依赖库**：OpenSSL 3.5+, mozjpeg, zlib, liblcms2, tg_angle
