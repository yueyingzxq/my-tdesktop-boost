========================================================================
             Telegram Boost 极速增强版 —— 功能使用指南
========================================================================

欢迎使用 Telegram Boost 极速增强版！本版本基于官方 Telegram Desktop 源代码深度构建，
在保留官方全部安全特性与端到端加密的同时，优化了大量日常使用体验：
突破单线程下载限速，提供 16 通道并发与流媒体秒播；视频连续播放；原位转发不中断；原生自动更新等。

------------------------------------------------------------------------
一、核心功能特性与开关位置
------------------------------------------------------------------------
1. 【Network Boost（16 通道并发与极限下载加速）】：
   - 功能说明：
     * 文件下载（另存为）：开启 1MB 超大分片 + 16 通道并发，默认始终彻底拉满网络带宽；
     * 视频在线播放：128KB 切片 + 8MB 激进预读缓冲 + 32 切片并发流水线，支持下方「Playback Threads」滑块在 2~16 线程间自由调节并发数；
     * 长连接保活：120 秒 Keep-Alive 热连接，切换视频与连续下载无需重复握手。
   - 开关位置：
     「设置 (Settings)」➔「高级 (Advanced)」➔「数据与存储 (Data and storage)」➔「Network Boost / Playback Threads」（默认开启，16 线程）。

2. 【连续播放与仿 YouTube 控制】：
   - 功能说明：
     * 视频播放时，控制条右侧新增仿 YouTube 风格滑动开关；
     * 开启后当前视频播完自动无缝衔接下一个媒体，且保持全屏状态不退；
     * 视频切集 1 秒后自动平滑淡出隐藏播放进度条，沉浸式观影无打扰；鼠标滑动立刻重新呼出。
   - 开关位置：
     内置视频播放器底部控制条右侧的【自动播放开关】（点击即可开启/关闭）。

3. 【原位转发不中断】：
   - 功能说明：
     * 无论全屏或窗口模式观看视频时，右键点击“转发”或快捷键转发；
     * 视频在背景持续流畅播放，转发目标选择面板在视频上层原位浮现；
     * 选择目标并发送后浮层自动退出，观看与分享两不打扰。

4. 【原生自动更新】：
   - 功能说明：
     * 软件内置专属 GitHub Release 自动更新检测通道；
     * 每次有新版本发布时，聊天列表顶部会自动弹出绿色【Update Telegram】按钮；
     * 点击即可一键自动下载并热替换重启完成升级，告别手动覆盖；
     * Windows 用户亦可随时在安装目录下双击运行【一键更新.bat】快速同步。

5. 【本地无限置顶会话（Unlimited Local Pinned Chats）】：
   - 功能说明：
     * 解除官方非会员仅 5 个置顶会话的上限限制；
     * 支持在「所有聊天」「归档会话」「自定义分组」「收藏夹」「群组话题」中无限置顶与自由拖拽排序；
     * 前 5（会员前 10）个置顶继续正常同步云端，超出部分安全保存在本地 tdata 中，软件重启后自动恢复原排序（注意：本地超限置顶仅在当前设备生效，不会同步到手机端）。
   - 开关位置：
     「设置 (Settings)」➔「高级 (Advanced)」➔「数据与存储 (Data and storage)」➔「Unlimited Local Pinned Chats」（默认开启）。

------------------------------------------------------------------------
二、快捷键与操作技巧
------------------------------------------------------------------------
- 按【F】键：一键全屏 / 退出全屏（照片与视频均原生支持）；
- 按【Shift + >】：切换下一个视频；
- 按【Shift + <】：切换上一个视频；
- 按【Ctrl + 左右方向键】：在全屏状态下无缝切换上一个 / 下一个媒体；
- 查看图片：单张图片支持按 F 全屏展示，切换回视频后播放控制条自动隐退。

------------------------------------------------------------------------
三、老用户无缝迁移数据（免重新登录）
------------------------------------------------------------------------
如果您之前电脑上已经登录过其他版本的 Telegram Desktop：
1. 找到您原版 Telegram 目录下的【tdata】文件夹；
2. 完整复制该【tdata】文件夹；
3. 粘贴到本增强版软件目录下（与 Telegram.exe 同级）；
4. 双击打开 Telegram.exe，直接自动登录原账号，所有聊天记录、登录会话和偏好设置 100% 完整保留！

------------------------------------------------------------------------
四、安装与放置建议
------------------------------------------------------------------------
【Windows 用户】：
1. 本程序为绿色便携版，解压即可直接运行，无需执行繁琐的安装程序。
2. 建议解压到非系统盘的独立英文目录，例如：
   ✔ 推荐：D:\Software\Telegram\ 或 E:\Telegram_Boost\
   ❌ 不要放在：C:\Program Files\、桌面或系统下载目录（避免 Windows 权限拦截导致无法自动更新）。

【macOS 用户】：
1. 下载 `Telegram_macOS.zip` 解压后，将 `Telegram.app` 拖入系统“访达 -> 应用程序” (Applications)。
2. 首次打开如遇提示“无法打开，因为无法验证开发者”：
   - 方法一：在“应用程序”中找到 Telegram，右键选择“打开”，在弹出的提示中点击“打开”即可；
   - 方法二：打开系统“终端” (Terminal.app)，执行以下命令解除门禁隔离：
     xattr -cr /Applications/Telegram.app

------------------------------------------------------------------------
五、一键汉化语言包
------------------------------------------------------------------------
登录成功后，如果界面为英文：
1. 在任意聊天框或搜索栏中输入并打开官方语言包链接：
   https://t.me/setlanguage/zhcncc
2. 在弹出的窗口中点击 “Change” / “更改语言”；
3. Telegram 界面立刻变更为简体中文！
