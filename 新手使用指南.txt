========================================================================
             Telegram Boost 极速增强版 —— 新手使用指南
========================================================================

欢迎使用 Telegram Boost 极速增强版！本版本基于官方 Telegram Desktop 源代码深度构建，
在保留官方全部安全特性与端到端加密的同时，优化了大量日常使用体验：
突破单线程下载限速，提供 16 通道并发极速下载；视频连续播放；原位转发不中断；原生自动更新等。

请阅读以下指引，只需 2 分钟即可完成配置并开始使用！

------------------------------------------------------------------------
一、安装与放置建议
------------------------------------------------------------------------
【Windows 用户】：
1. 本程序为绿色便携版，解压即可直接运行，无需执行繁琐的安装程序。
2. 【重要】解压到非系统盘的独立英文目录，例如：
   ✔ 推荐：D:\Software\Telegram\ 或 E:\Telegram_Boost\
   ❌ 不要放在：C:\Program Files\、桌面或系统下载目录（避免 Windows 权限拦截导致无法自动更新）。

【macOS 用户】：
1. 下载 `Telegram_macOS.zip` 解压后，将 `Telegram.app` 拖入系统“访达 -> 应用程序” (Applications)。
2. 【首次打开如遇提示“无法打开，因为无法验证开发者”】：
   - 方法一：在“访达 -> 应用程序”中找到 Telegram，按住 Control 键或右键点击它，选择“打开”，在弹出的安全对话框中点击“打开”即可。
   - 方法二：打开系统“终端” (Terminal.app)，复制并执行以下命令回车：
     xattr -cr /Applications/Telegram.app
     （该命令用于清除 macOS Gatekeeper 下载隔离属性，完全安全，执行后即可双击直接打开）。

------------------------------------------------------------------------
二、网络代理设置（国内使用必读）
------------------------------------------------------------------------
Telegram 在国内必须配合网络代理工具（如 v2rayN、Clash、Surge、Sing-box 等）使用。

【方式 1：手动配置代理（最推荐，简单秒通）】
1. 确保您的本地代理工具处于运行状态。
2. 打开 Telegram，在登录界面点击左下角或右上角的“小盾牌” / “连接设置” (Connection settings)。
3. 选择“添加代理” (Add proxy)：
   - 协议类型：选择 SOCKS5 或 HTTP
   - 主机名 (Hostname / Server)：填写 127.0.0.1
   - 端口 (Port)：
     * 如果使用 v2rayN：通常填 10808 (SOCKS5) 或 10809 (HTTP)
     * 如果使用 Clash / Surge / Clash Verge：通常填 7890
     * 如果使用 Shadowsocks：通常填 1080
4. 点击保存，小盾牌显示打勾 / 在线，即可秒速收发短信验证码并正常登录！

【方式 2：使用代理工具的系统全局代理 / TUN 虚拟网卡模式】
- 在 Clash 中开启 "TUN Mode" (虚拟网卡)，或在代理工具中开启全局代理，Telegram 将无需任何配置直接联网。

------------------------------------------------------------------------
三、老用户无缝迁移数据（免重新登录）
------------------------------------------------------------------------
如果您之前电脑上已经登录过其他版本的 Telegram Desktop：
1. 找到您原版 Telegram 目录下的 【tdata】 文件夹；
2. 完整复制该 【tdata】 文件夹；
3. 粘贴到本增强版软件目录下（与 Telegram.exe 同级）；
4. 双击打开 Telegram.exe，直接自动登录原账号，所有聊天记录、登录会话和偏好设置 100% 完整保留！

------------------------------------------------------------------------
四、新手一键汉化语言包
------------------------------------------------------------------------
登录成功后，如果界面为英文：
1. 在任意聊天框或搜索栏中输入并打开官方语言包链接：
   https://t.me/setlanguage/zhcncc
2. 在弹出的窗口中点击 “Change” / “更改语言”；
3. Telegram 界面立刻变更为简体中文！

------------------------------------------------------------------------
五、特色功能使用说明
------------------------------------------------------------------------
1. 【16 通道极速并发下载】：
   - 全自动生效！下载大文件、超清视频、无损音频时，自动建立 16 条独立传输通道并发抓取，彻底跑满您的千兆宽带。
2. 【连续播放与仿 YouTube 控制】：
   - 播放视频时，底部控制栏新增【自动播放】开关（类似 YouTube 右下角滑动开关）；
   - 开启后当前视频播放完毕自动无缝播放下一个媒体，且全屏状态保持不退！
   - 视频切换后 1 秒内播放进度条自动淡出隐藏，沉浸式观影无打扰；鼠标滑动立刻重新呼出。
   - 支持快捷键：
     * 按 `F` 键：一键全屏 / 退出全屏（照片与视频均支持）；
     * 按 `Shift + >`：下一个视频；
     * 按 `Shift + <`：上一个视频；
     * 全屏下按 `Ctrl + 左右方向键`：全屏无缝切换上一个 / 下一个媒体。
3. 【原位转发不中断】：
   - 在沉浸式查看视频时点击“转发”，视频在背景持续播放，转发菜单原位浮现，丝毫不打断观影体验。
4. 【原生自动更新】：
   - 软件内置 GitHub 自动更新检测通道，当有新版本发布时，主界面聊天列表底部或设置内会自动弹出官方风格的“更新 Telegram”按钮；
   - 点击即可一键自动下载并重启完成升级，告别手动覆盖。

------------------------------------------------------------------------
六、常见问题与技术支持
------------------------------------------------------------------------
Q: 为什么登录时收不到短信验证码？
A: Telegram 官方目前对新设备登录优先发送验证码到【已登录的手机客户端/其他设备】中。
   请先确保手机端已登录 Telegram，并在手机 App 的官方通知服务号 (Telegram) 中查看 5 位登录码。

Q: 提示网络连接中 (Connecting...)？
A: 请检查第“二”步代理配置，99% 的连接问题是端口未填对（检查代理软件设置里的本地监听端口）。
