========================================================================
             Telegram Boost 极速增强版 —— 新手使用指南
========================================================================

欢迎使用 Telegram Boost 增强版！本版本基于官方 Telegram Desktop 最新源码构建，
在保留官方全部安全特性与隐私功能的同时，深度优化了国内网络使用体验：
突破单线程下载限制，带来 16 通道并发极速下载与沉浸式视频连续播放体验。

跟着本指南，只需 2 分钟即可从零完成配置使用！

------------------------------------------------------------------------
一、安装与放置建议（绿色免安装）
------------------------------------------------------------------------
1. 本程序为【绿色便携版】，解压即可直接运行，无需执行安装程序。
2. 【重要建议】：请解压到非系统盘的独立英文目录，例如：
   √ 推荐：D:\Software\Telegram\ 或 E:\Telegram_Boost\
   × 切勿放置在：C:\Program Files\、桌面临时文件夹或系统受限目录（避免 Windows 权限拦截导致无法自动更新）。

------------------------------------------------------------------------
二、网络代理配置（国内使用必读）
------------------------------------------------------------------------
Telegram 在国内必须通过代理工具（如 v2rayN、Clash 等）连接网络。

【方式 1：软件内手动配置（最稳妥）】
1. 打开您的代理软件（确保正常开启并处于连接状态）。
2. 打开 Telegram.exe，在登录界面点击左下角或右上角的【小盾牌/连接设置】
   （若已登录，可在：设置 -> 高级 -> 连接类型 -> 使用自定义代理）。
3. 点击【添加代理】：
   - 代理类型：选择 SOCKS5 或 HTTP
   - 服务器（主机名）：填 127.0.0.1
   - 端口：填您的本地代理端口
     * v2rayN 默认一般为：10808 (Socks5) 或 10809 (HTTP)
     * Clash / Clash Verge 默认一般为：7890
4. 点击保存，稍等片刻界面变为【已连接（Connected）】，即可正常登录和收发消息！

【方式 2：浏览器一键配置链接】
在代理软件启动的前提下，直接在浏览器中打开如下快速链接并点击允许跳转：
- v2rayN 用户：tg://socks?server=127.0.0.1&port=10808
- Clash 用户：tg://socks?server=127.0.0.1&port=7890

------------------------------------------------------------------------
三、老用户无缝迁移数据（免重新登录）
------------------------------------------------------------------------
如果您之前电脑上已经登录过官方原版或其他第三方 Telegram：
1. 彻底退出之前的 Telegram 软件。
2. 打开旧版 Telegram 所在的文件夹，找到名为【tdata】的文件夹。
3. 将整个【tdata】文件夹复制并粘贴到本 Telegram Boost 所在的文件夹下。
4. 双击打开 Telegram.exe —— 即可瞬间免密免验证码登录！
   所有联系人、聊天记录、会话置顶和个人设置 100% 完整继承！

------------------------------------------------------------------------
四、新用户登录与界面汉化
------------------------------------------------------------------------
1. 登录：输入您的国际区号和手机号（国内手机号为 +86），输入验证码登录。
   （提示：官方通常会优先将验证码发送到您其他已登录的手机/平板设备上的 Telegram 官方聊天窗口中，请留意查收）。
2. 汉化：官方原版默认无简体中文，您可以点击以下官方汉化包链接：
   https://t.me/setlanguage/zhcncc
   在弹出的窗口中点击【Change】即可一键切换为简体中文。

------------------------------------------------------------------------
五、特色功能使用说明
------------------------------------------------------------------------
⚡ 1. 16 通道并发极速下载
   - 无需手动配置，下载大文件、蓝光视频或大图集时自动激活 16 线程并行拉取，突破延迟瓶颈，轻松跑满家庭百兆/千兆带宽。

🎬 2. 视频自动连续播放（YouTube 风格开关）
   - 点击播放任意视频，在底部控制栏右侧带有仿 YouTube 风格的动画切换开关【自动播放】。
   - 开启后，当前视频播放结束会自动无缝切入下一个视频，观影无需频繁点击。

🖥️ 3. 沉浸式全屏与控制条优化
   - 视频连续播放切换到下一集时，控制栏会在 1~2 秒后自动优雅淡出隐藏，无需手动碰鼠标。
   - 查看图片或视频时，直接按下键盘【F 键】即可一键全屏/退出全屏。

↗️ 4. 原位画中转发（不中断播放）
   - 观看视频或多媒体时点击转发，直接在原位弹出转发浮层，背景视频继续流畅播放，不打断您的观赏节奏。

------------------------------------------------------------------------
六、后续如何更新升级
------------------------------------------------------------------------
本版本内置了 GitHub 原生极速更新引擎：
1. 【软件内无缝更新（推荐）】：
   每次有新功能发布时，Telegram 左侧聊天列表最底部会自动亮起蓝色的【更新 Telegram】按钮（或在设置 -> 高级中点击“检查更新”）。
   直接点击该按钮，软件将在后台自动下载并毫秒级重启完成更新，数据全程完整保留！
2. 【备用更新脚本】：
   如果在特殊网络下软件内更新失败，可随时双击文件夹内的【一键更新.bat】进行备用更新。
